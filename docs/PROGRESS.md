# Git Sheet 개발 진행 기록

## 사용자 요청과 진행 원칙

Microsoft Excel과 비슷한 스프레드시트로 점진적으로 확장한다. JDK 25/JavaFX를 유지하고 기능 이름만 추가하지 말고 실제 동작·저장·회귀 테스트까지 구현한다. 한도 회복 후에도 이 채팅에서 이어가도록 사용자가 요청했고 매시간 heartbeat 자동화가 등록되어 있다. 완료한 기능을 반복하지 않는다. 기존 창의 미저장 문서를 강제 종료하지 않는다.

## 2026-09-30 · 0.2 작업

- 저장/내보내기 성공 시 실제 절대 경로를 4초간 표시하는 알림. 반복 저장 시 타이머 재시작, 포커스 유지.
- Git: 저장소가 없는 문서와 첫 커밋 전 문서를 정상 안내. 변경 없는 커밋은 성공적인 no-op. 괄호가 있는 파일명은 literal pathspec으로 처리. 다른 staged 파일 보존. 작성자/인증 실패 안내. 중복 작업과 타임아웃 처리.
- Git 서버 화면: 로컬만 / GitHub / GitLab / Gitea / 기타 서버 선택, HTTPS/SSH Clone URL, 로컬 작성자 설정, 기존 origin 제안 및 보존, 서비스별 설정 유지, 연결 확인/push/fetch. Push 대상 확인 및 non-fast-forward 보호. 비밀번호·토큰 저장 안 함.
- Excel 유사 편집: 아래로/오른쪽 채우기(Ctrl+D/R), 상대·절대·혼합 수식 참조 이동, 텍스트/숫자/불리언과 서식 보존. 찾기/모두 바꾸기 및 수식 포함 옵션.
- 서식: 정렬, 기본 테두리, 글꼴 크기, 저장되는 열 너비. 큰 글꼴에 맞춰 가상 행 높이 계산.
- Ctrl+S 시 편집 중인 셀을 먼저 적용하도록 수정.
- 로컬 검증: BookTest 12개, GitServiceTest 13개, SheetEditsTest 5개, 총 30개 통과. 실제 JavaFX smoke test에서 편집·저장 알림·자동 닫힘·Gitea 설정 저장 통과. CI는 Windows/Linux에서 검증하며 최종 결과는 커밋의 GitHub Actions 확인.

## 다음 작업 (아직 미완료)

1. 행/열 삽입·삭제 기본 기능 완료 (아래 실행 기록 참고). 후속: Excel 표/배열 수식, 고급 객체 위치·참조의 구조 편집 지원.
2. 같은 문서 내부 복사/상대 수식 이동, 값만/서식만 붙여넣기 및 문자열 재편집 타입 보존 완료. 다음은 잘라내기(종속 참조 이동), 범위 전용 스냅샷 최적화 및 문서 간 복사.
3. 전체 범위 정렬·열별 필터·행 높이·셀 줄바꿈·병합/틀 고정 렌더링. 현재 정렬/필터는 화면 단위이다.
4. 파일 I/O 백그라운드화, autosave/recovery, delta 기반 undo로 큰 워크북 작업 개선.
5. 기본 유효성 검사/조건부 서식/저장되는 차트/이름 정의의 모델·편집·Excel 왕복 보존.
6. Git 브랜치/안전한 pull/시각적 셀 diff/충돌 해결. 열린 문서에 덮어쓰거나 다른 staged 변경을 손상하지 않을 것.
7. jpackage 설치/실행 패키지, 인쇄/PDF, 플랫폼별 UX 검증.

고급 Excel 엔진(VBA, Power Query, Power Pivot, 피벗 및 전체 동적 배열 함수)은 미구현이다. 전체 Excel 호환이라고 표시하지 않는다. 사용자가 우선순위를 바꾸면 최신 지시를 우선한다.

## 2026-09-30 · heartbeat: 행/열 구조 편집

- 시트 메뉴에 연속된 선택 행/열 삽입·전체 삭제 추가. 정렬·필터 중에는 해제 안내. 편집 중 입력을 먼저 적용하고 구조 변경은 한 번의 undo/redo로 복구.
- 일반 셀/범위/다른 시트/절대 참조/이름 정의 이동 및 삭제된 참조 #REF!. 끝부분의 대량 삭제에서 POI가 일부 참조와 셀을 남기는 문제를 회귀 테스트로 확인하고 보완. 삽입으로 Excel 한도를 넘는 기존 데이터·서식은 사전에 보호.
- 셀 서식/행 높이, 열 너비·숨김 이동, 병합 범위 확장·축소·삭제, 틀 고정 위치 갱신. 빈 열이 100열 밖에 있을 때 너비를 .gsheet에 저장하지 않던 문제 수정. 숨김 열도 선택적 필드로 저장해 기존 v1 파일과 호환.
- 제한: Excel 표/배열 수식의 구조 편집 미지원. 고급 객체 위치/참조 호환성은 추가 작업 필요. 병합/틀 고정/숨김 메타데이터의 실제 화면 렌더링은 기존 제한 유지.
- 검증: mvnw verify 총 40개 테스트 통과 (기존 30 + 구조 편집 10). 실제 JavaFX smoke에서 행/열 삽입·undo와 기존 편집/저장 알림/자동 닫힘/Gitea 설정 저장 통과. Windows/Linux CI는 업로드된 커밋의 Actions에서 확인.
- 다음 실행 우선 작업: 타입을 보존하는 내부 클립보드와 상대 수식 복사·붙여넣기, 잘라내기/선택하여 붙여넣기. 문자열 재편집 시 값의 타입이 의도 없이 바뀌는 문제도 함께 테스트·수정한다.

## 2026-09-30 · heartbeat: 타입 보존 클립보드

- CellClipboard에 복사 당시의 워크북 스냅샷을 보관하여 원본 변경/undo 뒤에도 값·타입·서식이 유지된다. 일반 붙여넣기는 상대/절대/혼합 수식을 이동하고 같은 문서의 다른 시트에도 적용된다. 겹치는 범위 붙여넣기와 한 번의 undo/redo 지원.
- 편집 메뉴에 값만/서식만 붙여넣기 추가. 값은 복사 시점의 계산 결과이며 대상 서식 유지, 서식만은 대상 내용 유지. OS 클립보드에는 TSV와 임의 식별자만 기록하며 현재 복사 식별자가 일치할 때만 내부 스냅샷을 사용한다. 문서를 바꾸면 내부 클립보드를 해제한다.
- 외부 텍스트 값 붙여넣기는 문자열로 입력한다. 문자열 재편집은 앞에 작은따옴표를 표시하여 =수식/숫자/불리언으로 변환되는 버그 수정. raw 저장 표현은 유지.
- 검증: 46개 테스트 통과(기존 40 + 클립보드/문자열 6). 실제 JavaFX smoke에서 문자열 재편집 타입 유지, 기존 구조 편집/저장 팝업/Gitea 설정 저장 통과. 로컬 smoke는 사용자의 OS 클립보드를 변경하지 않는다. CI는 업로드한 커밋의 Actions 확인.
- 다음 구체 작업: 잘라내기 후 이동에 대한 종속 수식 갱신/겹치는 범위/실패 시 원본 보존 테스트와 구현. 내부 클립보드의 전체 워크북 스냅샷을 범위 중심으로 줄이는 성능 개선. 이후 전체 범위 정렬과 열 필터.
- 제한: 잘라내기, 문서 간 타입·서식 복사, 다중 선택 반복 채우기는 미구현. 현재 복사는 전체 워크북 스냅샷 한 개를 메모리에 유지한다.

## 재개 체크

먼저 git status와 최신 커밋, 이 파일을 확인한다. 앞선 실행이 작업 중이면 중복 수정하지 않는다. 사용자가 이미 입력한 저장되지 않은 문서나 기존 원격 설정을 건드리지 않는다. 의미 있는 단위로 구현/테스트/커밋/push를 마친 뒤 이 기록을 갱신한다. 특별한 변화가 없으면 자동화 알림을 보내지 않는다. 사용자 입력/외부 계정 인증이 정말 필요한 작업만 보류하고 독립적으로 가능한 다음 항목을 진행한다.
